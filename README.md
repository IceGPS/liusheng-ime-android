# 留声输入法（Liusheng）· Android

*Offline Voice IME · 离线语音输入法*

## 一、开发目的

> 每一句话、每一张照片，都是你的数字资产。数据主权天生属于你——你不自己保管，就只能看着别人拿去变现：不打招呼，还用你的隐私给你喂广告。

1. **离线可用**：语音输入不再依赖网络，断网也能说，录音不出设备。
2. **本地沉淀**：每一次语音和文字输入，都在本地持续存储，并自动整理成可回看的文档。
3. **数据主权**：不用商业公司的在线输入法，不向任何第三方上传数据。

## 二、主要功能（V88）

1. **离线语音输入**：基于 sherpa-onnx + SenseVoice-Small 本地模型，按住说话、松开上屏，断网可用。
2. **拼音键盘**：QWERTY 全键盘，支持全拼和双拼两种方案，离线词库 89 万词条（源数据全量入册，每个汉字、每个读音都可达，V87 起覆盖审计守门）；⇪ 键为 Caps Lock（点按切换大小写，键面同步）。
3. **个人语料库**：每次语音输入的录音（AAC/M4A）和转写自动存档，通过 Syncthing 同步到 PC，长期积累。
4. **极简模式**：默认只有一行按键，把屏幕面积最大限度留给编辑区；需要时一键切换全键盘。
5. **多平台数据互通**：与 Windows 版留声输入法共用 Syncthing 同步方案。
6. **积极加载**：输入法启动时后台预热词典、双拼表、语音模型，首次输入零等待。
7. **剪贴板历史**：本机复制记录（50 条，置顶/删除/清空）+ 局域网内与自己电脑双向共享（配对 + AES 加密，不经过互联网）。
8. **用户词典自学习**：记住你的选词习惯（本地 SQLite 个人词典），常打的人名、术语越用越靠前；连续点选单字还能自动造词。
9. **汉字联想输入**：整串拼音转换完成、汉字上屏后，候选栏预测下一个词，可连环点选；个人习惯（本地 bigram 学习）优先于内置静态搭配表。
10. **回车键自适应**：回车键跟随当前输入框的声明变身"搜索 / 前往 / 发送 / 完成…"，按下真正触发对应动作（不少 App 只认系统动作回调，普通回车在里面点不动）。
11. **输入框类型适配**：金额、电话等数字/电话输入框聚焦时自动切数字键盘，切回文本框自动恢复之前的键盘。

---

这是 [voice-ime](https://github.com/IceGPS/voice-ime) 项目的 Android 端。

## 三、使用方法（V88）

### 安装

1. 从 GitHub Release 或 `dist/` 拿最新 `liusheng-ime-android-v*.apk` 传到手机
2. 点击安装（允许"安装未知应用"），**安装后核对文件大小**（见 Release 说明）
3. 打开 App，按引导完成：麦克风权限 → 启用输入法 → 切换到留声输入法
4. 首次使用拼音键盘时词库已内置，无需下载；语音模型（约 230MB）在设置页下载一次即可

### 极简键盘（默认）

只有一行（V67 起可收起的符号/数字区已退役）：`[ABC] [符] [123] [🎤] [。] [⌫] [⏎]`

- **ABC**：点按去拼音键盘；**长按 500ms** 调出系统输入法选择器
- **符 / 123**：点按直达符号键盘 / 数字键盘
- **🎤（空格键）**：短按=空格；长按 100ms=语音输入（键变红+轻振提示），松开转写上屏
- **。**：点按=句号（全角），上滑=逗号（极简键盘固定全角，无中/英切换）
- **⌫**：点按删一个，长按连删
- **⏎**：回车换行；跟随输入框声明显示动作标签（搜索/前往/发送等）并真正触发（见"回车键与输入框适配"）
- 设置入口：点手机桌面留声图标进 App，或去拼音键盘候选栏左侧 🎤

### 拼音键盘

点极简键盘底行 `[ABC]` 进入。QWERTY 布局：

- 第 1 行：Q～P；第 2 行：A～L；第 3 行：`⇪ Z X C V B N M ⌫`
- **点按字母**：输入拼音，候选栏显示汉字候选，点选上屏
- **按住字母上滑**：输入上标的数字/符号（如 Q 上滑出 `1`），有预览框和震动反馈
- **⇪ 键**：Caps Lock，点按切换全键盘大写/小写（键面同步显示）；中文模式+大写锁定时字母直接上屏，不走拼音（对齐电脑中文输入法）
- **M 右侧 ⌫**：搜狗式布局（V68 起），点按删一个、长按连删；底行也有 ⌫（有意重复）
- **统一底行**（四套键盘一字不差）：`[语音] [符] [123] [🎤] [。] [⌫] [⏎]`
  - **语音**：回极简键盘（拼音键盘上首键显示"语音"）
  - **符 / 123**：全局直达符号/数字键盘
  - **🎤**：短按=空格（有拼音时选首选）；长按 100ms=语音输入（键变红+轻振）
  - **。**：点按=句号，上滑=逗号；跟随中/英（中文全角 。/，，英文半角 ./.）
- **候选栏**（52dp，对齐搜狗）：可左右滑动浏览全部候选
  - 右端三个独立键（V70 起）：**📋** = 剪贴板历史面板；**中/英** = 点按切换（中文蓝色高亮）；**>** = 候选词浮层（4 列网格），点选上屏、点外面关闭
  - 左端 **🎤**：点按进入设置
- **拼音小耳朵**：悬浮气泡浮在候选栏上方（上圆下方），宽度随拼音动态变化
- **小鹤双拼零声母**：单韵母连按两下（aa/oo/ee）；复合韵母按"韵母首字母+韵母键位"（安=aj、昂=ah）；双字母韵母也可直接照字母打（安=an、爱=ai），两种打法并存（V85/V86）

### 符号 / 数字键盘

点任意键盘底行 `[符]` / `[123]` 进入，底行与拼音键盘统一：

- **符号键盘**：2 页（中文标点 24 个 / 英文符号 28 个）；"符"键显示 `1/2` 或 `2/2`，点按翻页；点选符号后**停留不自动跳回**，可连打
- **数字键盘**：4×5 数字 + 数学符号；`123` 键置灰（已在数字键盘，无动作）
- **空格键**：短按=空格，长按 100ms=语音输入（键面有 🎤 标记）
- **⌫**：点按删一个，长按 400ms 后连删
- **。**：点按=句号，上滑=逗号，跟随中/英

### 用户词典自学习（V72 起）

- **选词记忆**：点选过的候选词会被记住（本地 SQLite 个人词典，不联网）；同一拼音下选够 **2 次**才置顶——防手滑点错一次就被"永远记住"
- **自动造词**：连续点选单字会自动组词，如连点"朴 / 洪 / 琪"，下次打 `puhongqi` 直接出"朴洪琪"（立即生效）
- **删错词**：候选栏**长按**候选词，可删除个人词典里的词（静态词库的词不受影响）
- **管理**：设置页"个人词典（N 条）"入口 → 独立管理页，逐条查看/删除，或一键清空
- 回车上屏原始字母、语音上屏**不触发**学习

### 联想输入（V83 起）

- 选词上屏后，若**整串拼音已全部转换完成**（汉字已发送给前台 App），候选栏给出下一词预测，可连续点选（如选了"我们"→ 接着点"一起"）
- 拼音还没打完（组合区还有剩余拼音）时**不出现**联想，候选栏优先显示拼音候选（V84 定调，联想不许抢占未完成的输入）
- 预测来源：个人习惯优先——你真实上屏过的词序（本地 bigram 学习，和个人词典同一个库）；其次是内置静态搭配表（离线挖掘的常用词搭配）
- 点选联想词也会继续学习词序；语音上屏、回车上屏原始字母不触发联想；设置页可关（默认开）

### 回车键与输入框适配（V81/V82 起）

- **回车键自适应**：跟随当前 App 输入框的声明换标签——搜索 / 前往 / 发送 / 完成 / 下一项 / 上一项，没有声明动作时就是 ⏎；有动作时按下走系统动作回调真正触发（搜索框里按"搜索"就执行搜索）；拼音组合中按回车仍先上屏原始字母、不触发动作；四套键盘统一
- **数字框自动切换**：金额、电话等数字/电话输入框聚焦时自动切到数字键盘；切回文本框按你之前的键盘模式恢复；同一个框里你手动切走过，就不再强切回来；密码框不处理

### 剪贴板历史（V69 起）

- 入口：拼音键盘候选栏右端 **📋**
- 面板：面板打开时候选栏中央显示"剪贴板历史 · 共 N 条"（V78 起）；列表在面板内上下滚动（高度等于键盘区高度），每条预览最多 2 行（文本 + 复制时间 + 来源）；点一下直接上屏；长按删除/置顶；底部有"清空"和"关闭"按钮
- 本机历史：SQLite 存储，最多 50 条，置顶不参与淘汰；只记文字不记图；不联网
- 局域网共享（需配对）：手机复制 → 电脑直接进 Windows 剪贴板（Ctrl+V 即用）；电脑复制 → 手机历史列表（标注"来自 XX 电脑"），点选上屏；AES 加密；设置页可开关

### 设置页

- 顶部标题"留声离线语音输入法"（V74 起）
- **转写引擎**：端侧优先（默认）/ 仅局域网
- **VAD 模式**：点按开始、静音自动停止（默认关闭为按住说话）
- **拼音方案**：全拼（默认）/ 小鹤双拼
- **个人词典（自学习）**：入口行，点进独立管理页（逐条删除/清空）
- **联想输入**：开关（默认开）；关掉后选词上屏不再预测下一词
- **端侧模型**：SenseVoice-Small INT8，约 230MB，下载进度和 SHA256 校验
- **剪贴板共享**：总开关（默认关，首次配对后自动开）；已配对设备列表，可取消配对

### 语音转写后端

- [x] 可插拔接口：`service/asr/AsrBackend`（`transcribe(pcm16k): AsrResult(text, latencyMs)`）
- [x] 端侧 `SherpaAsrBackend`：sherpa-onnx 跑 SenseVoice-Small INT8
- [x] 局域网 `LanAsrBackend`：WebSocket 发往 PC 服务端（CapsWriter 协议，备用）
- [x] mDNS 自动发现局域网服务端（`_voiceime._tcp.`）
- [x] 每次转写耗时打 logcat（tag=`VoiceIME`）

## 四、版本演进：V8 → V88

### V8 → V23：端侧 ASR 路线确立（2026-10-12 ~ 10-13）

V8 还是"计划用 MNN 跑 Qwen3-ASR"的阶段。V17–V22 在真机上反复闪退，先后怀疑过
`decodingMethod`、`provider`、sherpa 版本号，四个盲修全错。直到用 `adb logcat`
抓到 `F/sherpa-onnx` 的 FATAL 行，才定位根因：传了非空 AssetManager 却用绝对路径
加载模型。V23 一行修复（传 `null`），SenseVoice-Small 在小米 MIX FOLD 4 上跑通。

**思路变化**：从"猜参数"到"先看日志"。立下规矩：真机/native 闪退先抓 logcat，
FATAL 行会直接告诉你答案。

### V24 → V26：数据链路和连接（2026-10-13）

- V24：录音（AAC）+ JSONL 转写日志存到 `/sdcard/VoiceIME`，供 Syncthing 同步——
  "数据主权"从口号变成目录结构。
- V25：VAD 模式（点按开始、静音 1.5 秒自动停），默认关闭，设置页有开关。
- V26：mDNS 自动发现局域网 PC 服务端。认识到多服务器是鸿杰局域网的常态，
  不是边缘情况。

### V27 → V29：极简键盘的输入能力补完

- V27：⇧ 开关展开数字/标点区（默认关闭，状态持久化）。
- V28：数字标点区改两行置顶。
- V29：跟随系统深浅色，按键间隙缩小。鸿杰评价"非常漂亮，超出预期"。

**思路变化**：极简不等于残缺。语音是主力，但数字符号必须触手可及，
否则连输个验证码都要切输入法。

### V30 → V31：录音格式和命名

- V30：WAV 改 AAC/M4A（MediaCodec 系统编码），体积缩小一个数量级；
  定下规矩：移动端录音统一 AAC，永不用 WAV。
- V31：文件名从纯时间戳改成 `(时间戳)识别文本前15字.m4a`，
  对标 CapsWriter——在文件管理器里一眼能看到录音内容。

### V32 → V34：拼音键盘（2026-10-16）

转折点。鸿杰用了几天极简键盘后说："再改进一下就可以替代手机默认输入法，
但输入个别汉字（尤其生僻字）麻烦，语音不是强项，必须有键盘输入。"
他本人用小鹤双拼，但要求同时支持全拼让别人也能用。

- V32：QWERTY 手绘键盘 + 候选栏 + 语音/拼音模式切换。引擎方案上放弃了
  librime JNI（NDK + boost/leveldb 依赖重、CI 构建慢、难调试），改用
  **纯 Kotlin 引擎 + RIME 词库数据**：雾凇拼音 88 万词条预处理成 27MB
  二进制，迭代快、无 native 崩溃、APK 更小。`PinyinEngine` 接口预留，
  以后可换 librime 而不改 UI。
- V33：修 CI 漏打 assets 的 bug（`aapt2 link` 缺 `-A` 参数），词库随包发布。
- V34：设置页加拼音方案切换（全拼/小鹤双拼），模糊音默认关闭
  （鸿杰：z/zh 等六组声母对他"区分非常清楚"）。

### V35 → V37：候选词体验对标搜狗

- V35：候选栏横滑 + 点 `>` 弹浮层面板。对比搜狗"整屏替换"的做法，
  改成浮层盖在键盘上方——点选上屏、点外关闭，不用来回切换。
- V36：候选字 19sp → 22sp。实测发现字形和搜狗一样大，观感差异来自
  行高留白，加大字号的同时加了上下内边距。
- V37：极简键盘数字区 `0-9` 改 `1-0`，与拼音键盘上标顺序一致。

### V38 → V39：语音输入统一

- V38：拼音键盘空格键中央 🎤 改按住录音（红底反馈），和极简键盘行为一致。
  用户原话："空格键不管在哪个键盘上都可以保持一致的行为：做语音输入。"
- V39：修三个 bug——极简键盘录音红底提示、折叠屏展开时 mic 热区失效
  （热区缓存没跟上尺寸变化，改按住瞬间动态计算）、候选浮层抢焦点
  导致拼音直上屏（PopupWindow 改不可聚焦）。

### V40 → V41：极简键盘收尾

- V40：符号区/数字区改横滑扩充（符号 17 个、数字+数学符号 22 个）；
  新增了一行独立空格键。
- V41：用户纠正——"不应该新增一行，把原来的语音输入键改造一下就可以了"。
  删掉新增行，原"🎤 按住说话"键改成 🎤 居中：按住中央录音、点其他位置
  输入空格。界面做减法，回到 7 个键。

**思路变化**：听用户的。开发者觉得"加一行"顺手，用户觉得"改原来"
更干净——输入法的每一行高度都是寸土寸金。

### V42 → V46：模型下载链路打磨（2026-10-17）

- V42：模型下载允许手机流量（先弹确认框"模型约 230MB"）。
- V43/V44：老用户设置里存的还是旧 GitHub 下载地址（404），自动迁移到
  HuggingFace 地址。
- V45：删除设置页过时的占位说明文字。
- V46：拼音键盘两处改进——回车直接上屏原始拼音字母（不转汉字）；
  空格键录音时整个变红（与极简键盘一致）。

### V47：候选栏防闪烁 + 首字母提示（2026-10-17）

- 候选栏高度固定 60dp，拼音显示区改成"小耳朵"圆角气泡（不占一整行）——
  目标 App 的编辑区不再随输入状态伸缩闪烁。
- 首字母高频单字动态提示：只输一个声母（如 `l`）时，按首字母给高频单字
  （了/里/来…），选中后清空整个拼音串。

### V48 → V50：空格键语音/空格统一（2026-10-17 ~ 10-18）

- V48：语音模式空格键按用户新定义——短按任意位置=空格，
  长按（500ms）任意位置=语音输入；VAD 模式走旧中央热区逻辑。
- V49：三处改进——①双拼模式回车上屏用户实际键入的原始字母
  （`vk` 不展开成 `zhang`）；②长按判定 500ms→**100ms**；
  ③拼音键盘空格键同逻辑（删除中央热区）。
- V50：长按触发录音的瞬间轻振一下，提示已进入录音。

### V51 → V52：Caps Lock（2026-10-19）

- V51：拼音键盘第三行 Shift 键（↑）改成 Caps Lock（⇪）——点按切换
  全键盘大写/小写，键面字母同步显示；单次大写循环删除。
- V52：中文模式 + 大写锁定时，字母直接上屏（不走拼音），
  对齐电脑中文输入法；小写状态照常拼音输入中文。

- `e66f744`（CI `39624268544`，APK 24,561,351 字节，AAB 24,590,891 字节）：
  鸿杰报障：拼音删除恒多按一次（hjzi 4 字母要 5 下退格，单
  字母亦然，每次必现），且正文里常出现落单的单个字母。根因：
  `PinyinInputController.refresh()` 组合变空时只调
  `finishComposingText()`——该 API 按 AOSP 语义只摘除组合区
  标记、不删字符，最后一个组合片段被"扶正"为正文残留：删空
  那一按看似空删除，不补按而继续打字/回车/切键盘，残留就
  留在正文里。修复：新增连接身份守卫，组合变空时先
  `setComposingText("",1)` 清文本再 finish；同批覆盖切中/英、
  切语音、重置时整串拼音显示文本漏进正文的放大版。控制器级
  仿真 `tools/backspace-sim/`（场景 A–G）守门：双拼 4 按、
  全拼 5 按、删空续打无残留；符号/极简键盘退格无此问题；
  基线零回归。鸿杰真机验证通过。

## 五、致谢

### 中州韵（RIME）

拼音键盘的词库和双拼方案全部来自 RIME 社区：

- **词库数据**：rime-ice（雾凇拼音）的 `base.dict.yaml`（55 万行）、

  （zh→v、ch→i、sh→u 等），保证和主流双拼输入法键位一致。
- 本项目只用了 RIME 的**数据**，引擎是独立实现的纯 Kotlin 代码，
  没有使用 librime。

### CapsWriter（HaujetZhao）

项目的起点，Windows 版直接基于 CapsWriter-Offline 改造：

- **局域网协议**：Android 端 `LanAsrBackend` 用的就是 CapsWriter 的
  WebSocket 协议，PC 服务端零改动即可对接。
- **录音命名**：`(时间戳)识别文本.m4a` 的文件名格式是对标 CapsWriter 学的。
- **JSONL 转写日志**：按天记录转写文本、时间戳、音频路径的思路来自 CapsWriter。
- **每日文档**：把一天的输入汇总成文档、再做 AI 总结的两层设计，
  是在 CapsWriter 日记功能基础上的延伸。

## 六、已知限制

- 密码框/银行类 App：按设计不在支持范围（本工具只做日常便捷输入）。
- 邮箱/网址输入框暂未做自动键盘适配（数字/电话框已支持，V82）；数字键盘主页缺 #/*（在符号键盘英文页）。
- iOS / Linux / macOS 版按计划推进中。

## 七、构建

需要 JDK 17 + Android SDK（API 34）+ kotlinc，云端 CI 自动构建。
本地手动构建：

```bash
export JAVA_HOME=<jdk17> ANDROID_HOME=~/android-sdk KOTLINC_HOME=<kotlinc>
tools/build-apk-manual.sh dist/liusheng-ime-android-vX.apk
# 自动完成：aapt2 编译资源（含 assets 词库）→ kotlinc 编译 → d8 dex → 对齐 → apksigner 签名
```
